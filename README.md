# Strata

本地优先的极简层级思维导图编辑器，重点是稳定的树编辑交互，而不是自由画布功能。

## 核心交互

- 单击节点选中，双击在节点原位置编辑；`Enter` 提交，`Esc` 取消。
- 选中节点后按 `Enter` 创建同级节点并立即编辑；根节点没有同级节点时创建子节点。
- 选中节点后按 `Tab` 创建子节点并立即编辑。
- 选中节点后按 `Delete` 删除整个子树；选中节点被删除时，选中并居中树顺序中的最后一个末级节点，只剩根节点时回到根节点。若通过其他操作删除节点且原选中节点仍在，则保留并聚焦原选中节点；根节点不可删除。
- 滚轮以鼠标位置为中心缩放，范围为 `25%–300%`，也支持触控板捏合。拖动画布空白处平移，缩放后拖动距离仍与鼠标一致。
- 分支节点旁的 `−` / `+` 按钮收起／展开后代；选中分支后也可按空格切换。收起仅隐藏后代，不影响完整内容导出；折叠状态随 JSON 保存，旧文件默认全部展开。
- 新增节点后保持缩放比例，将新节点移到画布可视区域中心并立即编辑；删除后的聚焦也保持原比例。目标被折叠时自动展开其祖先。手动平移后不会被重复聚焦拉回。
- 拖动节点卡片及其子树时，节点和连线跟随鼠标；有效落点显示放下后的虚线占位节点和连线。
- 横向布局：目标上部插入同级之前，中部作为子节点，下部插入同级之后。纵向布局对应左部、中部、右部；`Esc` 取消拖拽。
- 拖动操作使用稳定节点 ID；不能拖到自身或自己的后代，非法拖动不会先删除源节点。
- 画布方向键：`←` 选父节点，`→` 展开并选第一个子节点，`↑` / `↓` 选上一条／下一条同级。没有相邻同级时，沿祖先层级寻找上一条／下一条分支；到整棵树边界保持选中。节点进入可视区域，缩放不变；编辑文字时方向键仍移动光标。

## 素材库

- 顶部 `素材库` 打开右侧面板，卡片按两列、1:1 正方形排列，显示标题和正文摘要；搜索同时匹配标题和正文。
- 面板顶部 `新增` 打开标题和多行正文弹框，`保存` 或 `⌘S` 保存素材；正文中回车正常换行。新素材排在最前面。
- 卡片右上角 `…` 或右键菜单可查看／编辑完整内容，也可删除素材。
- 先选中画布节点，再点击卡片：将完整正文作为该节点的最后一个子节点，**不含素材标题**，保持倍率并居中选中新节点，键盘焦点返回画布。没有选中节点时不能插入。
- 素材独立保存在 `~/Library/Application Support/Strata/material-library.json`，增删改保存后立即生效，重启／重新编译后仍保留。已插入节点是独立副本，编辑或删除素材不会改变导图。

## 文件

- `新建`（`⌘N`）和 `清空` 都会回到全新的空白主题；两者结果相同，但分别表达“开始下一项工作”和“清除当前内容”。当前画布有内容时会先确认，避免误删未保存工作。
- `打开` / `保存` 使用 JSON 文件，保存是显式操作，不自动写盘。
- `文本预览` 按树的顺序导出 Markdown：分支按深度使用 `#`、`##` 等标题，末级节点不加标题标记。复制成功后关闭预览，并显示短暂的成功提示。

## AI 整理

- 工具栏的 `AI 整理` 打开长文本输入弹窗；右上角齿轮配置 OpenAI 兼容 API 基础地址、密钥和模型。
- `读取模型` 获取 `/models` 列表，也可手动输入模型名称；生成使用 `/chat/completions`。
- `代理地址（可选）` 留空时遵循系统网络设置；系统代理关闭时，可填写本机 HTTP 代理（例如 `http://127.0.0.1:7897`），对模型读取和生成同时生效。代理地址随设置保存，HTTPS 证书校验保持开启，不修改全机代理。
- 设置点击 `保存` 后生效。地址和模型保存在 `~/Library/Application Support/Strata/ai-settings.json`，密钥保存在 macOS 钥匙串的 `design.wisepulse.strata.ai` 服务中，按 API 地址隔离，不随 App 重编译丢失。
- 远程地址要求 HTTPS；本机 localhost 可使用 HTTP。只发送输入的提示词，不自动上传现有导图。生成成功后替换当前导图，已有内容先确认，失败或取消保留原图。
- 生成输出校验上限为 500 节点、12 层、单节点 2000 字；提示词不在客户端截断。
- `AI 优化` 将当前思考树整理为工具无关、可直接复制的提示词：保留原始意图、事实、约束和有效层级，按内容需要重组任务、背景、输入、输出与验收标准，不套固定模板。
- 优化不会猜测目标工具或补造事实；只有缺失会直接阻碍执行时，才以 `待补充：……` 标出最多三项关键缺口。发现冲突时保留双方并标为 `待确认：……`。

## 构建与验证

```sh
swift build
swift run Strata
bash Tests/run-smoke.sh
bash package-app.sh
open .build/Strata.app
```

## 当前限制

`package-app.sh` 固定使用本机开发证书指纹与应用标识，避免每次重编译改变钥匙串访问身份；其他机器可用 `STRATA_SIGNING_IDENTITY` 指定证书。AI 自动测试使用明确的 HTTP 测试夹具，不等于真实服务验证；真实模型调用需要用户在 App 中配置后验收。

这是可靠交互优先的核心切片，不包含撤销/重做、自由画布布局、协作、全局快捷键或 `.mm` 导出。树视图使用随文字尺寸变化的节点卡片和递归层级布局；后续扩展必须先保持三段拖放语义和树模型操作不变。自动回归使用独立 AppKit Smoke 程序；`Tests/StrataTests` 中的 XCTest 文件目前未加入 Package 测试目标。
